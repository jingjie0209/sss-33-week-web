# SSS 儿歌学习计划

一个纯静态的 33 周 / 99 首 SSS 儿歌学习站点：儿歌计划、核心句型、名词 / 动词 / 形容词卡、万物贴、亲子口语、波西和皮普、复述、随机组句、游戏库、闯关奖励与亲子阅读。

## 本地运行

```bash
python3 -m http.server 4184 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4184/>。

> 请使用 HTTP 服务访问，不要直接双击 `file://` 打开；部分浏览器能力在 `file://` 下会受限。

## 代码结构

- `index.html`：应用外壳与脚本加载入口。
- `app.js`：核心渲染逻辑、打卡状态、句型与歌曲详情。
- `integration.js`：今日学习、游戏库、闯关、亲子阅读、家长设置。
- `styles.css` / `integration.css`：样式。
- `*-data.js`：内容数据（儿歌、句型、词卡、游戏等）。
- `assets/`：闪卡图片与音频素材。
- `tmp/`：生成数据的本地构建脚本与源文件，不参与运行，也未提交到仓库。

## 功能入口

- 今日学习 / 周计划 / 整体进度表
- 33 周 SSS 儿歌计划表 / SSS 儿歌和句型对应表 / 核心句型
- 随机组句（全部句型 / 已打卡句型，3 档难度）
- 名词、动词、形容词卡与开口练习
- 万物贴、亲子口语、波西和皮普、复述
- 游戏库、闯关与奖励、亲子阅读、家长设置

## 进度存储

学习进度保存在浏览器 `localStorage`，不会上传服务器；换浏览器或清缓存后会丢失。

## 歌曲详情新增模块

每首歌曲详情页提供「句型 × 核心词汇完整问答」，用当前歌曲的核心词汇替换匹配句型，生成完整 Q / A 与中文提示，便于家长直接带孩子开口。
